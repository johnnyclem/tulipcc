# AMYboard Starter — classroom handout

---

## You need

1. An **AMYboard**  
2. A **USB-C data cable** (not charge-only)  
3. **Headphones** or a small speaker  
4. This Mac app: **AMYboard Starter**

## Do this

| Step | What to do | You should see / hear |
|------|------------|------------------------|
| 1 | Open **AMYboard Starter** | Window with JUNO / DX-7 chooser |
| 2 | Plug USB-C into board + Mac | Status turns **green — Connected** |
| 3 | Plug headphones into board **audio OUT** | (nothing yet) |
| 4 | Leave **DX7** selected (beige panel) | LCD shows a voice name |
| 5 | Tap voice **11** (or leave default) → **Play test** | Classic electric piano |
| 6 | Switch to **JUNO-6** (black panel) | Red LED + BANK/PATCH pads |
| 7 | Try Group **A**, Bank **1**, Patch **5** | “Moving Strings” |
| 8 | Play the on-screen keys or type **A S D F G H J** | Notes as you press |

## Factory memory maps

### DX-7 (128 sounds)

- **4 banks** (I–IV) × **32 voices** each  
- Default: Bank I, Voice 11 → **E.PIANO 1** (the famous one)

### JUNO (128 sounds)

- **Group A or B** × **Bank 1–8** × **Patch 1–8**  
- Matches factory codes like **A15**, **B61**  
- LED shows e.g. `2A` = Group A, Bank 2  

## Good first sounds

| Panel | Try this | Why |
|-------|----------|-----|
| DX-7 | Voice 11 | Classic electric piano |
| DX-7 | Voice 1 | Bright brass |
| DX-7 | Bank I voice 16 | Bass |
| JUNO | A15 (A · bank 1 · patch 5) | Moving strings |
| JUNO | A48 area — Group A bank 5 patch 8 | Synth bass |
| JUNO | A51 — Group A bank 6 patch 1 | Lead |

## If something’s wrong

| Problem | Fix |
|---------|-----|
| Never says Connected | Try another USB-C cable (must be data). |
| Connected but silent | Headphones in the **board**, not the Mac. |
| Flaky / no response | Close amyboard.com and any DAW. |
| Mac blocks the app | Right-click → **Open** → **Open**. |
| Stuck notes | Click **Silence**. |

## Teacher tips

- First 5 minutes: everyone on **DX-7 Electric Piano**, then flip to **JUNO Moving Strings** so they hear analog vs FM.  
- Faders on the JUNO panel for **VCF FREQ / RES** and **LEVEL** actually nudge the live sound (best-effort).  
- Optional USB MIDI keyboard → channel 1 plays whatever is loaded.  
- For sketch coding later: [amyboard.com](https://amyboard.com). This app is “sound in 60 seconds.”
